# sl limit tests, 2026-10-20 (build bd8ab76, Heretic Gemma-4 E4B 4-bit, prompt v5)

Method: web mode on ports 8811-8817 (`--lease`, `--rng jitter`), 8 sessions, driven via POST /say + /state + SSE. Haiku players (personas) plus Haiku analysts; the lead checked server behaviour itself. Raw data per session: `~/Claude-Workspace/gm-bench/sl-sessions/limit-<name>/` (turns.jsonl = input/story/state/latency per turn, sse.log = all SSE events with time offsets, world.json, hidden.json, chat.json, transcript.md, player-notes.md). Helpers: `limit-tools/` (say.py, sse.py, start.sh, PLAYER-RULES.md).

Sessions: normal (25 rows, harbour), rules (25, adversarial), chaos (command/HTTP fuzz, /neu, resume), cont (52, compaction + restart), dark (24, adult dark fiction), oracle (28), cli (stdin pipe), plus idle/quit test.

Evidence notation: `session:file:row` (row = 0-based line in turns.jsonl) or transcript/world.json field. "V" = verified by the lead directly; the rest comes from Haiku analyst/player reports (treat as likely, not proven).

## Timings
- Model load 1.8-1.9 s (also after idle unload/resume); GPU slot wait 0.3 s (queue empty).
- World gen (/welt start): 23.3 / 23.4 / 24.3 / 25.8 / 26-28 s (Prämisse 1.7 s, Orte 2-3.7 s each, Figuren 2.3-3.3 s each, Fäden ~2.8 s each, Startszene 3.4-7.5 s). /welt "text" | mix | orakel: 4.6-4.7 s including model load.
- Narrative turn (includes world-delta step): median 7.7-11.2 s per session (normal 8.7, rules 9.7, dark 7.7, cont 9.2), p90 ~13 s, max 15.3 s. Oracle-only turn 5-6 s. Non-LLM commands ~instant.
- First scene slower (13.7-17.3 s). Turn after reload from idle/restart: 27.4 s (cont row 51).
- No latency growth over 52 turns (SSE time per 10-turn block 5.1-6.5 s), no spike at compaction.
- Char rate in SSE ~165 chars/s (median); deltas are per character, tok/s is not logged anywhere (F17). Est. ~40 tok/s.
- Oracle statistics, 68 calls over all sessions (V): NEIN 37, JA 24, JA+ 4, NEIN+ 3; p/roll consistent in all cards (0 mismatches); no "Nein, aber"-style outcome exists in the answer set. GM chose odds "offen" in 39/68 (57%); "wahrscheinlich" 0/4 JA, "unwahrscheinlich" 1/8 JA (small n).

## Hard limits found
1. Web /say truncates input silently at 2000 chars (Web.swift `prefix(2000)`): a 2813-char input arrived cut, trailing marker lost (V). Body > 65536 B -> 413.
2. Web takes one job at a time: a second /say while busy is DROPPED (V: sse.log has "SL denkt noch …" info, the text is gone, UI input field was already cleared).
3. Compaction triggers at 14000 cached tokens (Game.maxCtx): hit at turn ~37 of cont (523 s). Afterwards the context keeps the last 24 msgs and the last 12 scene summaries.
4. `ort` world slot has 9 allowed values; anything else is coerced (F3).
5. Questions per scene 6, UI journal 8 entries, NPCs <= 20.

## Ranked findings
Severity: S1 breaks play / corrupts state, S2 clear quality or consistency failure, S3 polish. Cat: P = program, M = model logic.

### S1

**F1. [P] Harness tags leak into the player-visible story ("[Hinweis verdeckt]", "[Orakel] Antwort")**
- Repro: session with a thread clue reveal or /frage, then GET /state `story` (also the page reload).
- Evidence (V): cont:turns.jsonl rows 7/16/25/33 `me` text contains `[Hinweis verdeckt] Hinweis zu 'Wer meldet die letzte Reise nach unten': Sylis bei den Stiegen` (secret clue text shown before the player found it); /frage rows contain `Ich frage das Schicksal: …\n[Orakel] Antwort: NEIN`. Same in dark rows 2,3,9.
- Cause: `Runner.story()` strips only `[Gespräch]` lines and messages starting with `[Orakel]`; `[Hinweis verdeckt]` (Game.swift:135) and the /frage suffix are not stripped.
- Fix: keep display text separate from prompt text, or strip `^\[(Gespräch|Hinweis verdeckt|Orakel|Welt)\]` lines.

**F2. [M+P] Planner scaffold leaks into narration ("Erwartung …", "Deutunglichst plausibel ist, dass …")**
- Evidence (V): cont:transcript.md:57,76 `**SL:** Erwartung eines Kindes im dunklen, feuchten Keller. …` (2 SSE deltas begin with "Erwartung "); dark:transcript.md:42,53,116 `Deutunglichst plausibel ist, dass Morr, obwohl er lebt, keine unmittelbare Information liefert …` (3 of 20 narrations are meta-analysis instead of scene, "Deutung" fused with "möglichst").
- Cause: gate lines (Erwartung/Deutung/Antwort) are free text; the model puts them in the narration slot and nothing rejects it. Analyst: chat.json replays model output with "Erwartung:", "Ortswechsel/Zeitsprung:", "Frage:", "Werkzeug:" scaffold, so the model imitates it.
- Fix: validate narration (reject/resample if it starts with Erwartung/Deutung/Antwort or contains "plausibel ist, dass"); keep scaffold out of replayed history or make it uniform.

**F3. [P] World-gen slot coercion: the player's setting lands only in "muss"; `ort` falls back to "Kloster"**
- Repro (V): `/welt "Bergdorf im Alpental, die Pest geht um, ein Wanderarzt"` -> `ort: Kloster, epoche: antik, muss: [Bergdorf, Pest, Wanderarzt]` (cont world.json gen.slots). `/welt "Leuchtturm, Sturm"` -> `Ort: Kloster, Epoche: barock` (cli out.txt). `/welt mix "Kloster im Gebirge, Winter, Inquisition"` -> Gebirge dropped (rules). `epoche: antik` in 4 of 5 text-mode runs (Pest village, blood cult, harbour, Bergdorf), `licht: hell` for a blood cult.
- Consequence: thematically wrong worlds. normal: Glockengiesser + Schmuggler harbour became a salt-shortage plot with thread "Ladungchili"; cont: start place "Die Stiegen des Berggemeinschaftshauses", "Pest" absent from narration for 36 turns (F11); dark: first scene in a "Hafenschenke" (swamp requested).
- Fix: allow free-text ort/epoche, never default to the first/familiar enum value, pass `muss` verbatim into Prämisse and Orte prompts.

**F4. [P/M] Non-Latin glyph corruption of umlaut words in generated data**
- Evidence (V): `licht: "tr࿋"` (U+0FCB; the value comes from the fixed list "trüb", shown in "Welt-Vorgaben", rules world.json); `"Glཬkner"` (U+0F6C, Glöckner) in normal world.json npc kurz, in chat.json prompts 21+ times and in the Welt panel; analyst also found Devanagari `गरिrt` in a rules place description (visible in state.welt). 3 of 8 sessions.
- Suspected cause: grammar-constrained decoding of multi-byte characters in JSON strings (byte-fallback tokens / mask), or re-encoding when values are mapped. Once in world.json it is replayed in every prompt.
- Fix: validate all generated strings (reject chars outside Latin + punctuation, resample); map enum slots by index; add a decode test for every slot value through the grammar.

**F5. [P] World state does not follow the story (position, presence, inventory, death)**
- normal (analyst+player): after walking Hafenrand -> Salzmagazin -> back, /welt says `Ort: Salzmagazin`, Eira/Ragveig `anwesend: true`, `ort Salzmagazin` while narration has them at the Hafenrand (rows 13-22). Found crate: SSE `du +kleine, holzgebundene Kiste` but world.json `inventar: []`.
- rules: NPC `ort: "Kielboden des Schiffes"` for Ithror/Zernor/Kurfürst after the pirate bend, never updated, replayed in [Welt] (`Ithror (Schreiber · Kielboden des Schiffes)`). Player declared Ithror dead, oracle JA+, narration kills him, world says `Ithror lebt`, `zustand: []`. A granted item ("Siegel der Kapitulation") shows as a tool line but never in `inventar`.
- cont: Priester `bekannt: Besitzt die Wurzel` after the player took it; thread "Wo ist die Pestwurzel" still open; world.json `turn: 44` vs 52 rows.
- dark: Uranis `ort: "Hafenschenke (oder ein ähnlicher Ort, abhängig von der"` (V, placeholder text in state), Kara `Ort: Ritualplatz` while in the smithy, killed "Hohepriester" stays `hier`.
- cli (V): `du +Du bist oben angekommen` – a sentence became an inventory item.
- Cause: single constrained delta step may return `{}`, NPC `ort` not written on figurMoved, unknown references silently ignored, no narration-vs-state check.
- Fix: write ort for all `anwesend` NPCs on figurMoved, add a name-mentioned -> presence sync, dedicated `tot` state, reject parenthetical/placeholder strings and sentence-like items.

**F8. [P/M] Oracle logging and use inconsistencies**

## What held up
- Crash-free over ~190 turns: 0 errors/warnings in any server.log; chaos command/HTTP fuzz; /neu; restart; idle unload (SL_IDLE=15 -> GPU "frei", V).
- Resume after restart is exact (V): story, figure and world panel identical after restart (chaos, cont), next turn reloads model (~27 s).
- CLI pipe works (V): empty line skipped, /quit clean, exit 0, model unloaded.
- Narration format: 3-5 German sentences in all sessions apart from F2; no English output under injection; no tool syntax in narration.
- Oracle numerics correct (V), no refusals, no moralising.
