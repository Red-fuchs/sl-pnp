# Review: grammar engine (xgrammar 0.1.30 → llguidance) + anti-leak plan — 2026-10-20, Fable

**Verdict.** Migrate to llguidance, but gate it on a CPU-only spike; no hard blocker found. The ban trie is engine-independent (neither xgrammar 0.1.30 nor llguidance has a runtime "must not contain X": derivre `~`/`&` have no surface syntax, llguidance.h has no ban API, xgrammar `excludes` only in 0.2.8 JSON strings) → build it NOW in sl's own loop, it survives the migration unchanged. F4 is a confirmed xgrammar round-trip bug; the current regex workaround is correct, keep it as the stopgap.

**F4 root cause (verified in the vendored 0.1.30 source).** `shim.cc xg_compile_structural_tag` → `Grammar::FromStructuralTag` → `CompileGrammar(Grammar)` → cache key `grammar.ToString()` → cache miss re-parses via `FromEBNF` (grammar_compiler.cc:1469/1402). `GrammarPrinter::PrintByteString` prints codepoints ≤0xFF as `\xFC` (encoding.h:366); `ParseNextEscaped` treats `\x` as *arbitrary-length hex* (encoding.h:418) → `"tr\xFCb"` = U+0FCB (E0 BF 8B → "only 0xE0 allowed after tr"), `"Gl\xF6ckner"` = U+0F6C. Hits every const_string with ä/ö/ü/ß followed by a hex-digit letter (a-f/0-9: trüb, Glöckner, nächtlich). Regex path survives because `RegexToEBNF` emits one quoted segment per byte (`"\xC3" "\xBC"`). xgrammar main (2026-10-17) still has both halves; no upstream issue exists (search 2026-10-20; v0.1.30 = 2026-01-17, latest v0.2.8); the mlx-swift-lm copy is a flat `sync-xgrammar-source.sh` snapshot, hand patches get overwritten. Fix: stopgap = Grammar.swift non-ASCII→regex (in place) + `isCleanText` validator (in place); upstream = 1-line parser fix (`\x` = exactly 2 digits) or shim calling `compiler.CompileStructuralTag(json)` (no round trip). Devanagari in free text is the model, not the grammar.

**1. Spike (CPU only, no model load, ~1 day): go/no-go**
- Tokenizer: build `LlgTokenizerInitV2` from the Gemma-4 vocab (reuse `TokenizerVocabExtractor` bytes; `▁`→space, `<0xNN>`→raw byte, control tokens 0xFF-prefixed; tok_eos=106, extra [1,50]) OR pass `tokenizer_json`. GO iff `llg_tokenize_bytes("trüb Glöckner <turn|>")` == swift-transformers ids AND a `/[^\n]+/` grammar accepts a space-led token. (LiteRT-LM #3510/#3721 broke exactly here with raw SP pieces.)
- Umlaut: Lark `start: "trüb" | "Glöckner"` accepts the real tokens; const strings and `%json` with umlauts round-trip. GO iff byte-exact.
- Compile: narr grammar with bounded `{8,220}` sentences, DELTA_SCHEMA `%json`, NPC/thread grammars with 40-way enums. GO iff ≤50 ms each (xgrammar: 80 s bounded / 0.3 s unbounded per DESIGN-weltgen).
- Mask: p50 ≤300 µs, p99 ≤2 ms per token on 262k vocab vs xgrammar baseline from `--debug` "grammar mask µs/tok" (not in LIMITS, F17 — record it first). NO-GO if worse than xgrammar on free-text narration.
- Also: `llg_matcher_rollback` (backtrack_ok) on 200 committed tokens restores the mask; `llg_clone_matcher` works → replaces sl's "no Fork, roll back one matcher" hack.

**2. Integration shape.** `tools/build-llg.sh`: `cargo build --release -p llguidance` at a pinned tag (v1.9.1, 2026-09-30; llama.cpp pins v1.0.1, onnxruntime-genai via corrosion), arm64 `libllguidance.a` + `parser/llguidance.h` + `module.modulemap` as C target `CLlguidance` in Package.swift (root package → `linkerSettings .unsafeFlags(-L …)` allowed; or wrap as static xcframework `binaryTarget`). sl does not use `GuidedGenerationLoop`; `LM.core` only calls `computeMask/commitToken/rollback/isTerminated/tokens`. Add `protocol Constraint` with those five, `LlgConstraint` behind it (compute_mask → u32 bitmask words = same `MaskResult` layout, consume_token, compute_ff_tokens for `r.tokens`), xgrammar keeps the old class. `maskArr` and the ban trie plug into the same bitmask → no decode-loop change. A `LogitProcessor` wrapper is optional parity only.

**3. Port structural tags → Lark.** `G` maps 1:1: `.s`→`"lit"`, `.re`→`/re/`, `.js`→`%json {…}`, `.seq`→juxtaposition, `.or`→`|`, root `start:`. Keep each sentence as ONE terminal and repeat at rule level (`sent sent sent sent? sent?`), never single-char terminals (lexer ambiguity). Bounded repeats come back if the spike compile number holds. `regexEscape` stays (derivre is regex-syntax; no lookahead except trailing `stop`). `gcache` keyed by the Lark text as today. Test: every Gate combination + GenGr grammars compile and accept the fixtures in Tests/.

**4. Stopgap on xgrammar until then.** Keep non-ASCII→regex routing and unbounded tails; ship the ban trie + leak-guard changes below (engine-independent); do not vendor xgrammar 0.2.x (bounded-repeat regressions #972/#805, cache-collision bug #943 fixed only in 0.2.8). File the upstream xgrammar issue (needs user OK).

**Anti-leak plan: sound in shape, four concrete changes.**
- Director: feed only present bearers + clues reachable here (as `directorPass` already does), never full hidden.json; run the ban trie on the director output too (it must never need the term); skip the pass when the player's line names no bearer and no reveal is near — it costs ~3-4 s/turn (side cache re-prefills every time; cache its system prefix or accept it). Narrator blindness verified: hidden fields reach it only via `reveal()`, `[Regie verdeckt]`, and the regen note (topic, not term — correct per the "white bear" research).
- Ban trie: byte-level Aho-Corasick over the rare words of `secretList()` minus `knownText()` stems (same filter as `leakCheck` → one source of truth), variants orig/lower/Capitalised/ae-oe-ue-ss, matched at a word boundary with the terminal at the 5-6-letter stem, so the block hits at word START (no "Mitwarter" mid-word garbage). Apply only when `free` (mask popcount >3000, the repetition-penalty flag) so tails/enums/names are untouched; cache banned ids per automaton state; fold into the `maskArr` loop (zero extra per-token cost). Paraphrase leaks remain by design.
- n-gram guard becomes the backstop for variants: `nameLike` must match the full word, not the 5-letter stem (Brunnentor vs Brunnen → false regen = 8 s + retract); check per sentence at `.!?` in `NarrStream` to abort early; measure the false-positive rate offline on the 8 limit-session transcripts (no model needed).
- Keep narration hold + regen; the second regen note is appended to history permanently — fine, but strip it in `compact()`.

**Risks.** Rust toolchain in the build chain; SP tokenizer bytes (spike item 1); Lark lexer ambiguity on adjacent free-text terminals; llguidance perf numbers are vendor self-benchmarks (one enum-only paper says xgrammar masks faster); two engines = double test matrix if xgrammar is kept as fallback; Heretic + hard bans may raise garbled German (word-start banning mitigates).

**User decisions.** (1) Go/no-go thresholds above. (2) cargo as build dependency vs committed prebuilt `.a`. (3) Cut over fully or keep xgrammar behind the protocol. (4) File upstream xgrammar issue + mlx-swift-lm shim PR. (5) Director every turn (+3-4 s) vs only when a bearer is addressed. (6) Ban stems at word start (safer, blunter) vs full terms.
