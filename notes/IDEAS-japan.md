# Ideas from Japanese game design for sl (2026-10-20, Haiku research)

Top for sl (ordered by fit with world.json/oracle):
1. **Neglect + gossip** (Tokimeki Memorial): NPC attitude decays when ignored, gossip spreads along beziehungen.
2. **Question/answer arcs** (Higurashi): a thread has a `stage` (frage → hinweise → antwort); the answer is gated by a flag or oracle result.
3. **Secrets per NPC / hand-outs** (Japanese TRPG, e.g. Shinobigami 秘密/ハンドアウト; web sources weak): an NPC carries `geheimnis` + reveal condition; the player character gets a secret goal.
4. **Party talk** (DQ7): `/gespraech <npc>` → 1–2 lines + attitude delta, no scene change.
5. **Kishōtenketsu**: 4 beats per scene; "ten" = random event or "Nein, aber…".

Also:
- Persona deadlines (calendar/day-part budget per thread).
- Fire Emblem bond levels between NPC pairs; a death changes linked NPCs.
- Souls: location-bound traces/notes left by NPCs, visible only on revisit.
- Yakuza: location-bound side cases + request board.
- Danganronpa: NPC statements stored, contradiction with world → accusation with evidence.
- Shiren: stash survives death, death opens a rescue thread.
- Ma: "unklar" results leave gaps open.
